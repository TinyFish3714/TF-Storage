## 📖 简介

**TF Storage (TF存储)** 是一款专注于**大容量便捷存储**解决方案的 Minecraft 模组。

- 📦 海量存储 - 突破普通箱子限制
- 🎒 TF Bags & TF Chests - 模块化存储系统
- ⚡ 自动拾取与补货 - 智能物品管理
- 🛠️ 内置 3x3 合成栏 - 无需携带工作台
